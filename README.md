# exteraGram OSS (reconstructed)

Reconstructed sources of exteraGram 13.1.1 on top of the DrKLO/Telegram 13.1.1
upstream tree. The extera delta has been decompiled and partially rebuilt into
Java; the code is **not complete yet** and may be improved over time.

- Upstream: DrKLO/Telegram, commit `3de37c8` (13.1.1 / 7237)
- Reconstructed `com.exteragram.**` classes that compile with javac
- extera resources/assets (locales, atthemes, extera assets)
- Debug build: see Releases

Build with the standard Telegram Android Gradle setup.
